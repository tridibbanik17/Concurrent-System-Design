# Concurrent-System-Design

This repository contains models, exercises, and code for studying concurrent system design.  
It focuses on modeling concurrent processes, reasoning about safety and liveness, and implementing classical concurrency solutions in Java.

---

## Contents
- **LTSA Models (.lts)** — Labelled Transition System models for analyzing concurrent processes and detecting issues such as deadlocks and livelocks.
- **Java Implementations (.java)** — Example implementations of classic concurrency problems and utilities for experimenting with threads, locks, and synchronization.
- **Exercises & Examples** — Problem statements, test scenarios, and sample runs.

### Problems explored
- The Dining Philosophers  
- The Smokers Problem  
- Two Workers / Mutual Exclusion  
- Various process composition and safety-property examples
